# Задача: Chrome расширение для работы с транскриптами YouTube

> **Ralph Wiggum Mode**: Этот промпт выполняется итеративно. Каждую итерацию проверяй текущее состояние файлов и git history, чтобы продолжить с того места, где остановился.

## Цель
Создать Google Chrome расширение, которое позволяет пользователю в один клик отправить транскрипт YouTube видео в LLM для анализа.

## Функциональные требования

### 1. Извлечение транскрипта
- Расширение активно только на страницах youtube.com/watch
- Кнопка/иконка для извлечения транскрипта текущего видео
- Поддержка автогенерированных и ручных субтитров
- Обработка случаев отсутствия транскрипта (показать сообщение об ошибке)

### 2. Выбор LLM провайдера
- По умолчанию: ChatGPT (chat.openai.com)
- Дополнительно: Claude (claude.ai), Gemini (gemini.google.com)
- Выбор через popup меню или разные иконки/кнопки

### 3. Автоматическая отправка
- Открыть выбранный LLM в новой вкладке
- Автоматически вставить промпт с транскриптом в поле ввода
- Автоматически отправить сообщение (симуляция клика на кнопку отправки)

### 4. Система управления промптами

#### Промпт по умолчанию:
```
Проанализируй транскрипт YouTube видео "{video_title}" ({video_url}):

---
{transcript}
---

Задачи:
1. Краткое резюме (2-3 предложения)
2. Ключевые тезисы (bullet points)
3. Основные выводы и рекомендации
4. Временные метки важных моментов (если доступны)
```

#### База промптов:
- Хранение коллекции пользовательских промптов в chrome.storage
- Возможность добавлять, редактировать, удалять промпты
- Выбор промпта перед отправкой через dropdown в popup
- Предустановленные промпты:
  - **Резюме** — краткое изложение видео
  - **Ключевые моменты** — выделение главных тезисов
  - **Q&A** — режим вопрос-ответ по содержимому
  - **Перевод** — перевод транскрипта на другой язык
  - **Конспект** — структурированные заметки для обучения

#### Переменные для промптов:
- `{video_title}` — название видео
- `{video_url}` — ссылка на видео
- `{channel_name}` — название канала
- `{transcript}` — текст транскрипта
- `{duration}` — длительность видео

### 5. UI/UX
- Popup с выбором LLM и промпта
- Кнопка быстрой отправки (использует последние настройки)
- Страница настроек для управления промптами
- Индикатор загрузки при извлечении транскрипта

## Технические требования
- Manifest V3
- Минимальные permissions (только необходимые)
- TypeScript
- Хранение данных в chrome.storage.sync (синхронизация между устройствами)
- Обработка ошибок с понятными сообщениями
