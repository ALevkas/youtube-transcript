# YouTube Transcript to LLM

Chrome расширение для отправки транскриптов YouTube видео в LLM (ChatGPT, Claude, Gemini) для анализа.

## Возможности

- Извлечение транскрипта YouTube видео в один клик
- Поддержка автогенерированных и ручных субтитров
- Отправка в ChatGPT, Claude или Gemini
- Настраиваемые шаблоны промптов
- 5 предустановленных промптов:
  - **Резюме** — краткое изложение видео
  - **Ключевые моменты** — выделение главных тезисов
  - **Q&A** — режим вопрос-ответ
  - **Перевод** — перевод транскрипта
  - **Конспект** — структурированные заметки

## Установка

### Для разработки

1. Клонируйте репозиторий:
```bash
git clone <repo-url>
cd youtube-transcript-llm
```

2. Установите зависимости:
```bash
npm install
```

3. Соберите расширение:
```bash
npm run build
```

4. Загрузите в Chrome:
   - Откройте `chrome://extensions/`
   - Включите "Режим разработчика"
   - Нажмите "Загрузить распакованное"
   - Выберите папку `dist/`

### Для production

```bash
npm run build
```

Загрузите папку `dist/` как распакованное расширение или создайте ZIP для публикации.

## Использование

1. Откройте любое YouTube видео
2. Нажмите на иконку расширения
3. Выберите LLM провайдера (ChatGPT/Claude/Gemini)
4. Выберите шаблон промпта
5. Нажмите "Send to LLM"

Расширение автоматически:
- Извлечёт транскрипт видео
- Откроет выбранный LLM в новой вкладке
- Вставит промпт с транскриптом

## Управление промптами

Нажмите "Manage Prompts" для:
- Просмотра всех промптов
- Добавления собственных шаблонов
- Редактирования/удаления custom промптов

### Доступные переменные

| Переменная | Описание |
|------------|----------|
| `{video_title}` | Название видео |
| `{video_url}` | Ссылка на видео |
| `{channel_name}` | Название канала |
| `{transcript}` | Текст транскрипта |
| `{duration}` | Длительность видео |

```
├── popup/            # Popup UI

└── types/            # TypeScript типы
```
